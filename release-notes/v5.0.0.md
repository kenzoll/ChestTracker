### Исправлен подсчёт редких сундуков

Обычный сундук мог попасть в редкие из-за своего внутреннего имени. Теперь счётчик проверяет его реальный вид в записи матча и сохраняет эти данные между событиями повтора. Повторные данные об одном сундуке объединяются, а отменённый поиск не приписывается игроку как открытие.

После обновления приложение автоматически пересчитает сохранённые матчи, для которых ещё доступны исходные повторы. Начальная сумма останется прежней, а перед заменой результатов будет создана резервная копия истории. Если повтора уже нет или он повреждён, прежние числа сохранятся с отметкой о невозможности пересчёта.

### Остальные изменения

- Вкладки идут в порядке **Счётчик → Карта сундуков → Награды → История матчей → Настройки**.
- Напоминание о духе появляется через **20 секунд** после завершения записи матча.
- У неполученных наград появились базовый шанс за сундук и оценка вероятности хотя бы одного выпадения по общему счётчику. Прошлые открытия не повышают шанс следующего сундука; бонусные часы в оценку не входят.
- Иконка приложения, окна, напоминание и обложка проекта используют один логотип.
