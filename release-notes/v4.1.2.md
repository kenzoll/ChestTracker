### Надёжнее получаем новые версии

Изменили способ проверки обновлений: приложение получает информацию о новой версии прямо из файлов релиза. Это убирает зависимость от лимита запросов GitHub API.

Новая версия по-прежнему скачивается в фоне и устанавливается после закрытия приложения. Входить в GitHub для этого не нужно. История матчей, начальная сумма и полученные награды сохраняются.

**[Скачать приложение](https://github.com/kenzoll/ChestTracker/releases/download/v4.1.2/ChestTracker.exe)**
