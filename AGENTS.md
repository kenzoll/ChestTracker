# Тексты и публикация

Пользователь просит обновлять описание проекта и заметки к релизам вместе с изменениями приложения.

- Пишите по-русски, просто и по делу. В центре описания — функции и изменения, которые заметит игрок.
- Объясняйте конкретное поведение: что добавлено, что исправлено, как этим пользоваться.
- Не заполняйте описание повторяющимися тезисами про EXE, установку, контрольные суммы, внутренние номера сборок и технологии. Технические сведения оставляйте в документации для разработки.
- Не представляйте автообновления как отдельную особенность приложения в README. В заметках к версии упоминайте их только при конкретном изменении или исправлении.
- Не обещайте отсутствие багов, рост FPS или другие результаты, которые не проверены.
- Для каждой новой версии добавляйте отдельный файл release-notes/vX.Y.Z.md. Описывайте изменения этой версии; не копируйте один общий текст во все релизы.
- Когда меняются функции, проверьте README.md и при необходимости обновите его в том же изменении.
- Сохраняйте название приложения 4.1, пока пользователь не попросит поменять его. Технический Version служит для порядка автообновлений.
